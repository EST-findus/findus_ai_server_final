## 0. 이미 구축한 PC 에 추가할 것 (2026-10-22, ArcFace 신원 점수)

나이 변환 결과마다 "입력 사진과 같은 사람인가" 점수(`extra.identity`)를 붙이게 되면서 **패키지 1개와 가중치 1개**가 새로 필요하다. 이것이 없으면 나이 변환 요청이 실패한다.

```powershell
.\.venv\Scripts\python.exe -m pip install onnxruntime==1.19.2   # 또는 pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts/download_assets.py            # weights/arcface/w600k_r50.onnx (174MB) 만 새로 받는다
.\.venv\Scripts\python.exe scripts/check_setup.py                # "준비 완료" 확인
```

| 무엇 | 왜 | 메모 |
|---|---|---|
| `onnxruntime==1.19.2` | ArcFace 모델(`.onnx`)을 실행하는 패키지 | CPU 로 돈다. GPU 용 `onnxruntime-gpu` 는 필요 없고 GPU 메모리도 안 쓴다 |
| `weights/arcface/w600k_r50.onnx` (174,383,860 B) | ArcFace 얼굴 인식 모델 (insightface buffalo_l, ResNet50) | 스크립트가 insightface 공식 `buffalo_l.zip`(288MB)을 받아 이 파일만 꺼내고 zip 은 지운다 |

- 손으로 받을 때: https://github.com/deepinsight/insightface/releases/download/v0.7/buffalo_l.zip 을 받아 안의 `w600k_r50.onnx` 를 `weights/arcface/` 에 넣는다.
- 평가 설정(`configs/final.yaml` 의 `evaluators`)에는 AdaFace 도 있지만 서버는 ArcFace 만 쓴다 (`app/engine.py`). AdaFace 코드·가중치는 받지 않아도 된다.
- 이 ArcFace 는 **평가용**이다. 성별 보정의 학습용 IR-SE50(`weights/ir_se50/`), HairFastGAN 안의 `ArcFace/backbone_ir50.pth` 와는 다른 파일이며 서로 대신 넣지 않는다.
- 나이 변환이 요청당 약 0.8초 늘어난다 (이 PC, 나이 2개 기준 8.4초 → 9.2초).

### 3-1. 공개 출처에서 받기 (`python scripts/download_assets.py`)

| 파일 | 출처 |
|---|---|
| `weights/sam/sam_ffhq_aging.pt` | Google Drive id `1XyumF6_fdAxFmxpFcmPf-q84LU_22EMC` (ai_lab `scripts/download_weights.py` 와 같은 링크) |
| `weights/ir_se50/model_ir_se50.pth` | Google Drive id `1KW7bjndL3QG3sxBbZxreGHigcCCpsDgn` (ai_lab 과 같은 링크) |
| `weights/codeformer/codeformer_colorization.pth` | https://github.com/sczhou/CodeFormer/releases/download/v0.1.0/codeformer_colorization.pth |
| `weights/facexlib/detection_Resnet50_Final.pth` | https://github.com/xinntao/facexlib/releases/download/v0.1.0/detection_Resnet50_Final.pth |
| `weights/arcface/w600k_r50.onnx` | https://github.com/deepinsight/insightface/releases/download/v0.7/buffalo_l.zip 안의 파일 (스크립트가 꺼냄) |
| `third_party/HairFastGAN/pretrained_models/*` (17개) | https://huggingface.co/AIRI-Institute/HairFastGAN/tree/main/pretrained_models |

- Google Drive 는 하루 받기 횟수 제한에 걸릴 때가 있다. 실패하면 브라우저로 `https://drive.google.com/uc?id=<id>` 를 열어 받아 같은 경로에 둔다.
- HairFastGAN 은 추론에 쓰는 17개만 받는다 (저장소 전체는 7.7GB).
- 머리 합성 체크포인트(`Blending/checkpoint.pth`)가 쓰는 CLIP ViT-B/16 가중치도 필요하다. CLIP 패키지 설치 뒤 `python -c "import clip; clip.load('ViT-B/16', device='cpu')"`로 미리 받는다. CLIP의 공식 주소에서 `~/.cache/clip/ViT-B-16.pt`로 내려받으며, 서버 가중치 폴더와 별도로 보관된다.
- 머리 분할 코드가 처음 불러오는 ResNet18도 필요하다. `python -c "import torch; torch.hub.load_state_dict_from_url('https://download.pytorch.org/models/resnet18-5c106cde.pth', map_location='cpu', check_hash=True)"`로 미리 받는다. 기본 위치는 `~/.cache/torch/hub/checkpoints/resnet18-5c106cde.pth`다. 두 캐시 폴더는 서버 실행 계정이 읽고 쓸 수 있어야 한다.
