## 2026-10-20: 서버 저장소 만들기

- ai_lab 의 `/final` 화면 흐름(나이 변환 → 머리)을 FastAPI 서버로 옮겼다. 모델 코드(`src/`)와 설정은 그대로 복사했다.
- `scripts/sync_assets.py` 로 필요한 가중치·외부 코드·참조 사진만 복사 (694개, 8.8GB).
- 같은 사진(`ai_lab/data/samples/kid.jpg`)으로 확인:
  - 나이 변환 30·50세 12.0초. ai_lab 코드로 직접 돌린 30세와 픽셀 평균 차이 0.30, 최대 19 (성별 그림 보고 고치기의 bf16 계산 오차로 본다)
  - 머리(짧은 머리 + 애쉬 브라운) 58.2초, 색 차이 ΔE 0.1. ai_lab `HairPost` 로 돌린 것과 차이 0
  - 사진 바로 올려 머리(단발) 56.5초
  - 잘못된 나이·색·스타일, 경로 조작은 400/404 로 거절, 안경은 501
- 남은 문제: 이 사진의 머리 결과에 원래 앞머리 끝이 이마 가운데 세모 자국으로 남았다. ai_lab 코드로도 똑같이 나오므로 모델 쪽 문제다 (ai_lab docs/[22] 잔머리 보완 대상).

## 2026-10-20: 가족 LoRA 빼고 best_encoder 로 바꾸기, 시험 페이지

- 가족 데이터로 학습한 LoRA 두 개를 지웠다: latent 어댑터 `kin_latent_v3.pt`, 재구성 인코더 LoRA `recon_lora_true.pt` (가중치 파일, 설정, `src/kinship.py`).
- 나이 인코더를 받은 `best_encoder.pt` 로 통째 교체 (`aging.encoder_full`). ai_lab 의 `sam_encoder_full_ft.pt` 와 가중치가 완전히 같다.
- 나이 변환 경로를 `run_kinship` 대신 `Pipeline.run` 으로 바꿨다 (부모 반영이 없어져서).
- kid.jpg 확인: 30·50세 13.0초. ai_lab `/sam` 경로로 직접 돌린 30세와 평균 차이 0.20, 이전 LoRA 설정 결과와는 평균 26.6 차이 → 새 인코더가 쓰임. 이어서 머리(덮머 + 다크 브라운) 81.8초, ΔE 0.08. 안경 501.
- `/test` 시험 페이지 추가 (나이 변환 → 머리 → 안경, 참조 썸네일·색 고르기, API 키 입력). 페이지가 열리는 것과 스크립트 문법만 확인했고 브라우저로 눌러 보지는 않았다.
- 남은 일: best_encoder 조합을 dev 로 평가하지 않았다. 성별 방향은 LoRA 를 켠 latent 로 구한 것이라 뒤바뀜 비율을 다시 재야 한다.
