머리 스타일·색 POST /v1/hair

HairFastGAN 으로 모양을 바꾸고 머리 영역에 색을 칠한다. 1장에 1분 안팎 (모델을 처음 올릴 때 더 걸림).

참조 사진 (auto = 얼굴 폭이 가장 비슷한 것 자동)
색 없음 (참조 사진 색)

화장 POST /v1/makeup 서버에 아직 없음

ai_lab 에는 참조 사진의 화장을 옮기는 코드(src/makeup_transfer.py, CSD-MT / EleGANt)가 있지만 이 서버 API 에는 아직 넣지 않았다. 화면만 먼저 만들어 둔 상태.
